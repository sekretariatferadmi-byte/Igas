# Changelog

All notable changes to IGAS will be documented in this file.

## [1.0.0] - 2026-09-01

### Added
- Instagram Tools (Auto Poster, Bot, Reporter)
- Termux Bot (System Monitor, Task Scheduler, Notification)
- Web Application API (FastAPI)
- CLI Tools (File Manager)
- Web Scrapers (Instagram, Web, API)
- Configuration management system
- Comprehensive documentation
- Installation script for Termux and Linux
- Logging and error handling

### Features
- ✅ Auto posting to Instagram
- ✅ Bot automation (likes, follows, unfollows)
- ✅ Report inappropriate content
- ✅ System monitoring (CPU, RAM, Disk)
- ✅ Task scheduling
- ✅ Multiple notification methods
- ✅ REST API with FastAPI
- ✅ File management CLI
- ✅ Web scraping capabilities
